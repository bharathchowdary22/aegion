# ADR-007: Docker for Local Development

## Decision
We will use Docker and Docker Compose for defining and running our local development environment.

## Reason
Docker ensures that all developers have a consistent environment, eliminating "it works on my machine" issues. It allows us to easily spin up dependencies like PostgreSQL and Redis without requiring manual installation and configuration on host machines.

## Alternatives considered
- **Local native installation**: Prone to version mismatches (e.g., Python or PostgreSQL versions) across different developer machines.
- **Nix**: Powerful but has a steep learning curve for developers unfamiliar with it.

## Consequences
- Developers must install and understand basic Docker commands.
- Docker on certain operating systems (like macOS or Windows via WSL) can sometimes have performance overhead with mounted file systems.
