# ADR-004: PostgreSQL as Primary Database

## Decision
We will use PostgreSQL as the primary relational database for the platform.

## Reason
PostgreSQL is a powerful, open-source object-relational database system known for reliability, feature robustness, and performance. It has excellent support for JSON (JSONB), which is useful for storing semi-structured AI outputs or configurations, and supports powerful extensions.

## Alternatives considered
- **MySQL**: Solid, but lacks some of the advanced features and extension ecosystem (like pgvector) of PostgreSQL.
- **MongoDB**: Good for unstructured data, but we require strong relational guarantees for user accounts, RBAC, and billing.

## Consequences
- Need to manage schema migrations (likely via Alembic).
- Will require a managed PostgreSQL instance in production (e.g., Render or AWS RDS).
