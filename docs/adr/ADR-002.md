# ADR-002: Next.js for Frontend

## Decision
We will use Next.js (React) with TypeScript and Tailwind CSS for the frontend web application.

## Reason
Next.js provides a robust framework for building React applications with server-side rendering (SSR), static site generation (SSG), and seamless API routes. It has excellent support for TypeScript, leading to better type safety, and integrates well with our planned deployment target (Vercel). Tailwind CSS enables rapid, consistent UI development.

## Alternatives considered
- **Vue/Nuxt.js**: Strong alternative, but React has a larger ecosystem and community support for AI integration libraries.
- **Vanilla React (Vite)**: Lacks built-in SSR and file-based routing out-of-the-box, requiring more boilerplate for a full-stack feel.

## Consequences
- Requires developers to be familiar with the React ecosystem and Next.js specific conventions (like the App Router).
- Potential complexity with server vs. client components.
