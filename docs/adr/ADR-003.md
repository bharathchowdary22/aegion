# ADR-003: FastAPI for Backend

## Decision
We will use FastAPI (Python) for the backend services.

## Reason
FastAPI is highly performant, natively supports asynchronous programming, and automatically generates OpenAPI documentation. Python is the industry standard for AI and machine learning, meaning our backend can seamlessly integrate with AI libraries (e.g., LangChain, LlamaIndex) without needing a microservice bridge just for AI capabilities.

## Alternatives considered
- **Node.js/Express**: Familiar to frontend developers, but lacks the native AI/ML ecosystem of Python.
- **Django**: Too heavyweight for an API-first application where we don't need Django's built-in templating or admin panel.
- **Go**: Extremely fast, but lacks Python's mature AI ecosystem.

## Consequences
- Developers need proficiency in Python and asynchronous programming paradigms.
- Requires strict typing with Pydantic to maintain data integrity.
